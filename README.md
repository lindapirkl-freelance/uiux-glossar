# UI/UX-Glossar

Interaktives Nachschlagewerk für UI/UX-Begriffe. Jeder der 46 Begriffe hat ein echtes, bedienbares Mini-Beispiel direkt auf der Seite (echtes Modal, echtes Dropdown, echte Validierung usw.) statt einer bloßen Abbildung.

**Live:** https://lindapirkl-freelance.github.io/uiux-glossar/

## Stack

Eine einzige `index.html` — kein Build-Schritt, kein Framework, keine externen Requests. Vanilla HTML/CSS/JS, unterstützt Light/Dark Mode automatisch.

## Lokal öffnen

```
open index.html
```

## Deploy

Läuft über GitHub Pages direkt vom `main`-Branch. Änderungen an `index.html` committen und pushen — die Seite aktualisiert sich automatisch.
